# 🎵 Universal Music Saver

Универсальный, открытый инструмент для скачивания и умной синхронизации музыки из **ВКонтакте (VK)**, **Яндекс Музыки**, **YouTube Music** и **SoundCloud**.

Оснащён нативным графическим интерфейсом (GUI) на **CustomTkinter** с тёмной темой и консольной версией (CLI).

---

## 🚀 Основные возможности

- 🎧 **Мультиплатформенность:** автоматическое определение сервиса по ссылке:
  - **ВКонтакте:** вся аудиотека пользователя, альбомы, плейлисты в 320 kbps.
  - **Яндекс Музыка:** плейлисты по UUID (нового формата), канонические ссылки, альбомы и треки.
  - **YouTube Music / SoundCloud:** любые видео и плейлисты через встроенный движок.
- 🔄 **Умная синхронизация (Smart Sync):**
  - Проверяет существующие файлы на диске и в локальной базе `history.json`.
  - **Никогда не перезаписывает** уже скачанные треки.
  - Если вы добавили новые песни в плейлист, при следующем запуске скачаются **только новые треки**.
- ⏱ **Строгий порядок от новых к старым:**
  - Новая музыка всегда скачивается и нумеруется первой (`0001`, `0002`...).
  - Автоматически создаётся и обновляется файл плейлиста `Плейлист.m3u8` со строгим хронологическим порядком.
- 📦 **Автономный FFmpeg:** не требует ручной установки системных кодеков благодаря `static-ffmpeg`.

## 🖥 Установка и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/<ваш_аккаунт>/Universal-Music-Saver.git
cd Universal-Music-Saver
```

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 3. Запуск приложения

#### Графический интерфейс (GUI):
```bash
python app_gui.py
```

#### Консольная версия (CLI):
```bash
# Скачать плейлист или аудиотеку:
python app_cli.py "https://vk.ru/audios123456"

# Скачать плейлист Яндекс Музыки в определенную папку:
python app_cli.py "https://music.yandex.ru/playlists/..." -o /path/to/music
```

## 🛠 Сборка в исполняемый файл (.EXE / Linux Binary)

### Windows (.EXE)
В папке `build_scripts` подготовлен скрипт для сборки в один файл:
1. Запустите двойным кликом `build_scripts\build_exe.bat`.
2. Готовый файл появится в `dist\UniversalMusicSaver.exe`.

> **Автоматическая сборка на GitHub:** В репозиторий уже добавлен GitHub Actions workflow (`.github/workflows/build-windows-exe.yml`). При любом пуше в репозиторий GitHub автоматически соберет актуальный `.exe` на своих серверах!

### Linux
```bash
chmod +x build_scripts/build_linux.sh
./build_scripts/build_linux.sh
```
