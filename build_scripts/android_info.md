# Запуск и сборка под Android (APK)

## Почему десктопный Tkinter / CustomTkinter не компилируется в APK напрямую?
Библиотека **Tkinter** использует системные оконные менеджеры ПК (X11 / Wayland в Linux, Win32 API в Windows). 
В Android используется стек **Android View / Canvas / SurfaceFlinger** и JVM/ART, поэтому окна Tkinter не могут отображаться на экране смартфона без прослоек.

---

## 3 практических способа использования на Android:

### Вариант 1. Веб-интерфейс в локальной сети (Самый удобный)
Если запустить сервер на компьютере, к нему можно мгновенно подключиться с любого телефона:
1. Запустите веб-сервер на ПК (в локальной сети Wi-Fi).
2. На телефоне откройте браузер: `http://192.168.1.X:8080`.
3. В браузере Android нажмите: **«Добавить на главный экран»** (Add to Home Screen). 
4. Приложение установится как PWA-иконка и будет работать как отдельное мобильное приложение.

### Вариант 2. Запуск прямо на телефоне через Termux
Вы можете запускать этот же скрипт автономно внутри Android без компьютера:
1. Установите **Termux** (из F-Droid).
2. Выполните команды:
   ```bash
   pkg update && pkg install python ffmpeg git
   git clone https://github.com/<ваш_ник>/Universal-Music-Saver.git
   cd Universal-Music-Saver
   pip install -r requirements.txt
   python app_cli.py "ССЫЛКА_НА_МУЗЫКУ"
   ```
Треки будут скачиваться прямо в память смартфона в папку `Music`.

### Вариант 3. Сборка настоящего автономного APK
Чтобы собрать проект в чистый `.apk`, фронтенд интерфейса переносится на **Flet** (Flutter для Python) или **Kivy**:
1. Устанавливается `buildozer`: `pip install buildozer`
2. Настраивается файл `buildozer.spec`.
3. Запускается сборка: `buildozer android debug`.
4. На выходе получается готовый файл `.apk` для установки на любой Android-смартфон.
